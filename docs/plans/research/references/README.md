# Visual references

Mood references for the Innerverse direction in [the plan](../../innerverse-plan.md) (§3.5). All are the owner's own concept images, generated with ChatGPT and saved on 2026-10-28.

**They set the mood, not the characters.** Characters come from the code: every part is a plush sewn by the Felt Atelier engine from editor traits, which people can change to craft their own parts. The 3D plush and its 2D doodle are both drawn from that one record (see [the prototype's build](../prototype/build.py)). Never trace or copy a character from these images.
