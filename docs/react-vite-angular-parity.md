## Retained contracts and explicit differences

- The 64-item ResultsPanel and 147-item Descent are separate assessments. AI never changes canonical 147-item scores or the locally computed 64-item numeric/safety indicators.
- Future Self, journals, sealed texts and raw assessment inputs stay in explicit local backups. Default cloud/map sharing contains bounded display/aggregate data. Creating a legacy comparison code separately discloses that all 64 answers are shared until revocation.
- Share codes retain Angular's reusable-until-revoked behavior; no unsupported expiry or one-time guarantee is advertised.
- Angular's naive local booking timestamps remain compatible. The UI identifies the device clock; repeated autumn wall times have one slot. An IANA timezone/offset scheduling migration needs its own versioned contract rather than silently changing existing appointments.
- Stored legacy character shapes/traits stay readable; `egg` maps to Atelier `drop`. Existing headgear choices map to named sewn celestial toppers. Eyewear, bow and blush produce actual sewn details; portraits and universe nodes share stable DNA.
- XR controls depend on actual browser support. A hardware-free Chromium test cannot certify headset interaction.
