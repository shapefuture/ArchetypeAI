# React/Vite ↔ Angular functionality parity

## Goal and operating rules

Make the existing React/Vite application the complete user-facing implementation, preserving its visual system and interaction style. Angular remains buildable and is the behavioral/data-contract reference until the parity checks below pass. Do not remove Angular or unrelated repository changes during this migration.

A migration is complete only when the React path has equivalent behavior, Firebase/domain persistence, authorization, integrations, localization, and automated coverage—not merely a similar screen. Keep user data local by default where the React app promises local-first behavior; sharing/cloud writes must be explicit and understandable. The prioritized remaining implementation steps and exit checks are tracked in [`react-vite-angular-parity-plan.md`](./react-vite-angular-parity-plan.md).

## Required completion checks

- Every Angular user-facing feature has a React entry point and a real implementation; no mock users, randomized availability, local-only status changes, or dead controls remain.
- Firestore writes and reads use the existing narrow rules; tests cover owner, client, therapist, admin, and unauthorized cases. Any rules changes must preserve least-privilege access.
- Booking has a trustworthy source of occupied slots and handles races/duplicate requests; never silently treat a denied appointment query as an empty schedule.
- Cloud persistence/history, synastry, share-code redemption/revocation, and admin/client access work from React, with explicit consent for data sharing.
- Therapist/client linking, archive/restore, appointment lifecycle, assigned practices, exercise safety gates, and client-readable results are covered end to end.
- Assessment, check-in/JITAI, coaching, localization, billing, install/offline, and universe behavior have comparative tests or documented intentional differences.
- React/Vite build, Angular reference build, unit tests, Firestore rule tests, and the relevant browser smoke tests pass before Angular is retired.
