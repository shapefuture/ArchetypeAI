# ZERO-R Parts Map V3.1 — Antifragile Temporal Experience Runtime

## Objective
Deliver an installed-mobile PWA that feels native, remains useful offline, and keeps normal interaction off the network critical path. The production core is framework-independent and organized as a hexagonal architecture so UI, storage, rendering, compute and sync implementations can evolve independently.

## Product experience
- Persistent scene deck rather than page teardown.
- Local/private state.
- Current + next + next+1 future window.
- Direct manipulation gestures with compositor-first updates.
- Ambient visual field that degrades before interaction quality does.
- Reflection input persisted locally.
- Offline after first successful visit.

## Stable domain
State, transition, event, future candidate/object, effect class and capability concepts contain no browser/framework imports.

## Stable ports
InteractionPort, ScenePort, FuturePort, PredictionPort, SchedulerPort, StatePort, StoragePort, AssetPort, ComputePort, RenderPort, SyncPort, TelemetryPort, ClockPort, CapabilityPort.

## Production adapters
DOM scene adapter, CSS/Canvas renderer, IndexedDB persistence, local static predictor, economic scheduler, Rust/WASM compute with TypeScript fallback, queued HTTP synchronization with graceful offline behavior.

## Edge adapter
Cloudflare Worker + SQLite-backed Durable Object accepts asynchronous event batches at `/api/sync`; `/health` exposes version. Static assets are served through the Cloudflare Assets binding.

## Experimental adapters
Astro, Qwik, Solid, OPFS/SQLite, WebTransport, WebGPU, WASM threads and population priors are isolated experiments. They are promoted only after passing the same contract suite and outperforming the production adapter on an explicit metric.

## Performance contracts
- First visual response: target one frame on capable hardware.
- No network round trip on common navigation/interaction path.
- Persistence and sync never block local state commit.
- Pointer-move never updates application state.
- Visual quality degrades before interaction fidelity.
- Future speculation is budgeted by expected latency value per resource cost.

## Antifragility rules
A failed prediction adapter falls back to static graph. A failed compute accelerator falls back to TypeScript. WebGPU/Canvas failures fall back to lower-level renderers. Storage failure falls back to memory. Sync failure leaves the local experience intact.

## Development rule
Teams develop against ports and contract tests, not concrete infrastructure. No feature is allowed to import another team's adapter directly.
